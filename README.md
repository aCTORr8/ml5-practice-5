# Лабораторна робота № 5-6 — нейронна мережа і регуляризація

**Виконав:** Новак Сергій, ФЕІ-43с

Повнозв'язна нейронна мережа (MLP), реалізована з нуля на NumPy, та дослідження впливу регуляризації на датасеті FashionMNIST.

## Блок 1. Нейронна мережа з нуля

- архітектура 784 → 256 → 128 → 64 → 10: ReLU, Softmax, categorical cross-entropy, He-ініціалізація, mini-batch SGD;
- власні прямий прохід і backpropagation, без автоматичного диференціювання;
- перевірка градієнтів чисельним диференціюванням: без регуляризації, з L1, L2 і Dropout;
- графіки втрат і accuracy на Train та Validation;
- збереження ваг і конфігурації у `.npz` та відновлення в новий екземпляр мережі.

## Блок 2. Регуляризація

18 експериментів з однаковими початковими вагами та порядком батчів:

- без регуляризації;
- L2: λ₂ ∈ {1e-4, 1e-3, 1e-2};
- L1: λ₁ ∈ {1e-5, 1e-4, 1e-3};
- Dropout: p ∈ {0.1, 0.2, 0.3, 0.5};
- weight clipping: ±1 (за умовою) і ±0.1;
- gradient clipping: c ∈ {0.5, 1, 2};
- L2 + Dropout 0.2 з двома значеннями λ₂.

Для кожного експерименту — мертві нейрони по шарах, sparsity ваг, гістограми розподілу ваг, точність і втрати. Також є порівняльна таблиця та діаграми «мертві нейрони / sparsity vs validation accuracy».

## Запуск

Потрібен Python 3.10 або новіший. Команди виконуються з кореня репозиторію.

```bash
python -m pip install -r requirements.txt
jupyter notebook practice_5_neural_network.ipynb
```

Далі **Kernel → Restart & Run All**. Повний прогін триває близько 20 хвилин: 18 мереж × 40 епох на чистому NumPy.

## Основні результати

Дані: Train — 20 000, Validation — 10 000 (обидва з офіційного тренувального набору), Test — 10 000. Val accuracy — середнє за останні 5 епох.

| Метод | Dead neurons, % | Sparsity, % | Val accuracy | Val loss |
|---|---:|---:|---:|---:|
| Без регуляризації | 0.2 | 14.0 | 0.8683 | 0.370 |
| L1 (λ₁ = 1e-4) | 0.9 | 44.9 | 0.8644 | 0.366 |
| L1 (λ₁ = 1e-3) | 21.2 | 98.6 | 0.8141 | 0.494 |
| L2 (λ₂ = 1e-3) | 0.4 | 17.6 | 0.8658 | 0.361 |
| Dropout 0.2 | 0.0 | 14.1 | 0.8773 | 0.344 |
| L2 (1e-4) + Dropout 0.2 | 0.0 | 14.4 | 0.8779 | 0.342 |

Test accuracy: 0.8619 без регуляризації, 0.8681 з L2 + Dropout 0.2.
